# 처음 시작하는 분을 위한 가이드 — Claude로 제안서 슬라이드 만들기

> Claude(클로드)를 처음 써보는 분도 이 문서대로 따라 하면 표준 디자인의 제안서 슬라이드를 만들 수 있습니다.
> 어려운 설정은 없습니다. **Claude에게 말을 걸고, 보여주는 결과를 확인하고, 승인하면 됩니다.**

---

## 0. 준비물 (2가지)

1. **통합 마스터 문서**: `_shared표준_통합마스터_vNN.md` — 작업 규칙 전체가 담긴 파일
2. **템플릿 폴더**: `_shared/templates/` — 실물 pptx 파일들 (특히 `본문샘플_DB보안_원본13_v03.pptx`가 슬라이드의 원형)

> 두 가지를 전달받았다면 준비 끝. 없다면 공유해준 사람에게 요청하세요.

---

## 1. 시작하기 — Claude에 폴더 연결

1. Claude 데스크톱 앱(또는 claude.ai)에서 **새 Cowork 작업**을 시작합니다.
2. **"폴더 추가(Add folder)"** 버튼으로 위 준비물이 들어 있는 폴더를 연결합니다.
3. 연결이 되면 Claude가 그 폴더의 파일을 읽고 쓸 수 있게 됩니다.

---

## 2. 첫 대화 — 아래 문장을 그대로 복사해서 보내세요

**처음 한 번만 (환경 구성):**

```
연결한 폴더에 있는 "_shared표준_통합마스터" md 파일을 읽고,
문서 안의 AI 부트스트랩 절차대로 개별 파일들을 생성해서 작업 환경을 만들어줘.
이미 파일이 있으면 덮어쓰지 말고 차이만 알려줘.
```

→ Claude가 규칙 파일들을 만들고 "완료했습니다"라고 알려줍니다.

**슬라이드를 만들고 싶을 때:**

```
제안서디자인표준_공유본 문서의 규칙대로,
"(원하는 주제)" 내용으로 본문 슬라이드 1장을 만들어줘.
templates 폴더의 본문샘플 파일을 베이스로 사용하고,
만들기 전에 어떻게 만들지 먼저 설명해줘.
```

예시: `"4.2. 서버 이중화 방안" 내용으로 본문 슬라이드 1장을 만들어줘.`

---

## 3. 진행 중 인터랙션 — 이렇게 주고받으세요

Claude는 작업 전에 **계획을 설명하고 승인을 요청**합니다. 아래처럼 답하면 됩니다.

| 상황 | 이렇게 말하세요 |
|---|---|
| 계획이 마음에 들면 | `진행해` |
| 일부만 바꾸고 싶으면 | `2번은 표 대신 카드로 해줘. 나머지는 그대로 진행해` |
| 결과 이미지를 보고 수정하고 싶으면 | `섹션 제목이 길어서 두 줄로 꺾였어. 한 줄로 수정해줘` |
| 원본 디자인과 비교하고 싶으면 | `원본이랑 나란히 비교해서 보여줘` |
| 잘 모르는 용어가 나오면 | `섹션바가 뭔지 그림으로 설명해줘` |
| 저장 위치를 정하고 싶으면 | `완성본은 templates 폴더에 v01로 저장해줘` |

**중요한 원칙 3가지**
1. Claude가 보여주는 **렌더 이미지(그림)를 꼭 확인**하세요 — 글로 된 설명보다 그림이 정확합니다.
2. 숫자·기관명·인명은 Claude가 지어내면 안 됩니다. **"이 수치 근거 있어?"**라고 물어보세요. 예시값에는 "(예시)"가 붙어 있어야 합니다.
3. 파일은 덮어쓰지 않고 v01→v02처럼 **버전이 올라가야** 합니다. 이전 버전이 사라졌다면 지적하세요.

## 4. 결과 확인 — 초보자용 3분 검수

완성본을 받으면 PowerPoint로 열고 이것만 확인하세요 (자세한 기준은 공유본 §8 체크리스트):

- [ ] **보기 → 개요**를 눌렀을 때 슬라이드 제목이 보인다
- [ ] 한글 글꼴이 어색하게 바뀐 부분이 없다 (전체가 KoPub돋움체)
- [ ] 파란색 계열로 통일되어 있고 주황·연두 같은 색이 없다
- [ ] 글자가 상자 밖으로 넘치거나 겹친 곳이 없다
- [ ] 페이지 아래쪽이 텅 비어 있지 않다

이상이 있으면 Claude에게 그대로 말하면 됩니다: `3번 슬라이드 표가 겹쳐 보여. 수정해줘`

## 5. 자주 묻는 상황 (FAQ)

**Q. Claude가 뭘 물어보는데 무슨 말인지 모르겠어요.**
→ `초보자니까 선택지를 쉽게 설명해줘` 라고 답하세요. 설명 후 다시 물어봅니다.

**Q. 결과물이 문서 규칙과 다른 것 같아요.**
→ `제안서디자인표준_공유본의 검증 체크리스트로 네 결과물을 스스로 점검해서 보고해줘` — Claude가 자가 검증합니다.

**Q. 원래 있던 슬라이드를 새 디자인으로 바꾸고 싶어요.**
→ 파일을 첨부하거나 폴더에 넣고: `이 슬라이드를 표준 디자인으로 재디자인해줘. 원본과 비교해서 보여주고, 빠진 정보가 없는지 점검해줘`

**Q. 작업 도중에 멈췄어요 / 새 대화에서 이어서 하고 싶어요.**
→ 새 대화에서 폴더를 다시 연결하고: `_shared 폴더의 규칙 문서들을 읽고, 지난 작업 파일 (파일명)에 이어서 작업해줘`

**Q. 인쇄하면 왼쪽 구멍(링바인딩)에 내용이 걸리지 않나요?**
→ 인쇄 대화상자에서 **"실제 크기(100%)"**를 선택하세요. 이 템플릿은 A4보다 약간 작게 설계되어 100% 인쇄 시 제본 여백(~2cm)이 자동 확보됩니다. "용지에 맞춤"으로 확대 인쇄하면 안 됩니다.

**Q. 회사 로고나 발주기관 이름을 바꾸고 싶어요.**
→ `챕터바의 기관명·로고를 (기관명)으로 바꿔줘` — 표지·챕터바는 기관별로 교체하는 게 표준입니다.

## 6. 용어 미니 사전

| 용어 | 뜻 |
|---|---|
| 챕터바 | 슬라이드 맨 위 파란 머리띠 (부문 제목 + 로고) — 자동으로 붙음 |
| Key Message | 제목 아래 요약 문장 박스 ("~합니다" 체 1~2문장) |
| 섹션바 | 본문을 나누는 소제목 줄 — 파란 세로 막대 + 제목 + 회색 가로선 |
| 하위 섹션(원형 마커) | 섹션 안의 작은 구분 — 동그라미 마커, 가로선 없음 |
| 3점 소제목 | 가운데 정렬 제목 양옆의 점 3개 장식 |
| 쉐브론 | 화살표 모양이 이어지는 절차 도형 (①▶②▶③) |
| 스텝 플로우 | 번호 동그라미가 세로로 이어지는 단계 설명 |
| 렌더 | 슬라이드를 그림으로 변환해 보여주는 것 — 승인 전 확인용 |
| vNN | 파일 버전 (v01, v02…) — 덮어쓰지 않고 번호를 올려 저장 |
