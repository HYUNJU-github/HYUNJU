name: 검증
description: 주장 하나를 읽기 전용으로 판정한다 — 양성 대조·음성 대조·사용 조건·기능으로 판정·범위와 시각·0건 점검표·해소=내려감 7항, 표 1 + 3줄. "/검증 <주장>", "이 주장 맞아?", "검증해", "근거 있어?", "확인된 거야?" 에 쓴다. 파일을 바꾸지 않는다.
argument-hint: "<주장 한 문장>"
allowed-tools: Read, Grep, Bash(date:*), Bash(grep:*)
---
주장 `$ARGUMENTS`(없으면 부록 D 문서의 ⑤ 판정 행) 를 7항으로 판정 — 정의는 사내 설계 표준의 ④ 필수 4행(양성 대조·음성 대조·사용 조건·0건 점검표)+⑤ 필수 3행(기능으로 판정·범위와 시각·해소=내려감). 읽기·grep·`date` 만, 쓰기·재측정 없음. 근거는 잰 값·파일:줄·HUB 줄·사내 위키 카드 id — 카드는 검증일이 7일을 넘으면 근거로 안 친다(「재측정 요구」). 없으면 「근거 없음」.
상태 ✓/✗/—(해당 없음). 판정: ✗ 없음 → 통과 · ✗ 있음 → 실패(항목) · 근거 부족 → 미검증.
출력: `항목|상태|근거` 표 1(7행+판정) + 3줄. 끝: 표.md 「체인」 — 자동 연결·정지 3점(실패·미검증이면 정지).
